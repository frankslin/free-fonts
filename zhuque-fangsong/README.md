# Zhuque Fangsong Webfonts

Chunked woff2 webfonts for Zhuque Fangsong / 朱雀仿宋, generated from TrionesType/zhuque release v0.212.

> **⚠️ Prerelease / 預發布版**：上游 v0.212 為 prerelease（字體內部名稱標註
> "technical preview"），字符覆蓋與字形在後續版本可能變動，正式版發布後本
> package 會跟進更新。

```html
<link rel="stylesheet" href="./zhuque-fangsong.css">
```

```css
body {
  font-family: 'Zhuque Fangsong', serif;
}
```

The CSS uses 256-codepoint `unicode-range` chunks, so browsers only download the blocks needed by the page.
